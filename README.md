## Cara Membuka

1. Clone atau unduh repository.
2. Buka salah satu file `.html` menggunakan browser.
3. Gunakan navigasi, pencarian, filter, dan mode tampilan yang tersedia pada halaman dokumentasi.

Dokumentasi berjalan sebagai halaman HTML statis. Beberapa tampilan menggunakan Tailwind CSS, Font Awesome, dan Google Fonts melalui CDN sehingga koneksi internet mungkin diperlukan untuk tampilan lengkap.
